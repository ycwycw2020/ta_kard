# 塔卫牌局 · Windows 自适应节点安装包 v1.0.0

《明日方舟：终末地》同人卡牌游戏，非官方二创。此包用于加入现有游戏链，适用于 x64 Windows；本包加入 2026 年 9 月 27 日建立的现有测试链；9 月 28 日维护保留链与身份。

## 一键安装

1. 把整个 ZIP 解压到任意独立目录，不要直接在压缩软件内运行。
2. 双击 **Install.cmd**。
3. 填写**原服务器的 WLAN IPv4**。当前原服务器是 `10.195.244.225`。安装目录可修改，默认优先识别 `D:\card_endfiled_node4`，没有 D 盘时使用当前用户的本地应用数据目录。
4. 点击“一键安装 / 修复”，等待出现“节点已在后台启动”。首次安装需要联网下载运行环境，随后从现有节点同步区块。

新电脑自己的 WLAN 地址由安装器根据实际连接自动选择。例如当前新电脑是 `10.193.34.245`，无需再填写这个地址。文件夹支持中文和空格。安装到当前用户无权写入的目录时，请改用有写入权限的位置。

服务器必须已运行且新电脑能访问其 TCP 30303。可在新电脑用 `Test-NetConnection -ComputerName '10.195.244.225' -Port 30303` 检查。若失败，安装器会停止并提示原因，不会将“端口不通”误报为安装成功。更换新电脑后，原服务器的防火墙也需允许该电脑的地址。

## 已经安装过怎么办

本次是同链维护，选择原安装目录更新即可，保留节点密钥与链数据。只有仍连接 9 月 27 日之前旧链的设备才需另建目录；安装器会依据创世哈希拒绝混用不同链。

再次运行 **Install.cmd**，选择原节点目录。安装器保留该节点的密钥与链数据，备份发生变化的配置，修复旧的 `value/Count` 节点列表和同步配置，再启动节点。

已经健康运行的节点会直接显示状态，不重复启动。若旧版节点仍在原来的控制台运行，先在原窗口按 `Ctrl+C`，再运行安装器；安装器不会擅自停止无法确认归属的进程。不要删除原节点目录来“重装”。

更换服务器网卡地址后，重新运行安装器并填写新地址即可。原服务器的节点身份、链 ID 和创世文件必须仍属于同一套游戏链。

## 日常操作

安装目录中会生成：

| 文件 | 用途 |
|---|---|
| `Start-Node.cmd` | 启动本机节点；重复启动不会产生第二个进程 |
| `Status-Node.cmd` | 查看节点身份、连接数、区块高度和同步状态 |
| `Stop-Node.cmd` | 停止该安装器管理的节点 |
| `logs\node.log` | 完整运行日志 |
| `node-settings.json` | 自动选择的本机 IP、端口、运行环境位置 |
| `backups` | 修复时自动保留的旧配置 |

安装完成后节点在后台运行，关闭安装窗口即可。**重启电脑后请双击 Start-Node.cmd**；此版本不注册开机服务。安装器缓存和运行环境目录需保留，不要在节点运行期间移动安装目录。

`running: true` 表示节点进程和 RPC 正常，`peers` 大于 0 表示已连接；区块高度逐渐接近原节点才表示已追上主链。启动初期 `syncing: false` 也可能只是暂时尚未选中同步目标，不能只凭这一项判断同步完成。

## 命令行方式

在解压目录的 PowerShell 中执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1 -NoGui -ServerIP '10.195.244.225' -InstallDir 'D:\我的塔卫节点'
```

可选 `-PrepareOnly` 只准备文件，`-Plan` 只检查并显示计划，`-RuntimePath` 复用包含 `besu-26.8.1` 与 `jdk-25.0.4.1+1` 的运行环境目录。常规安装不需要这些选项。

## 自动处理的内容

- 检测并准备 Node.js、Java 和 Besu；下载固定版本并核对 SHA-256。
- 根据到服务器的实际 IPv4 路由选择本机 IP；P2P/RPC 端口冲突时选择可用端口。
- 生成独立节点密钥；保留已有密钥、链数据和自定义的目录内数据路径。
- 写出标准字符串数组形式的 `static-nodes.json`，只连接用户填写的可达原节点；设置 `sync-min-peers=1`。
- RPC 仅监听本机回环地址；外部节点默认作为同步节点加入，不自动获得验证者资格。
- 中断后可重试；Besu/Java 下载支持续传。已有正常环境会复用。

建议预留至少 3GB 内存和 10GB 起步磁盘；Java 最大堆为 1GB，链数据会随运行增长。首次需要访问 Node.js、GitHub/Adoptium 下载站点。受网络限制时可使用已有完整运行环境。

## 游戏网页与数据库

此包安装**区块链节点**。玩家数据库仍在原 Windows 主机，不会在新电脑创建另一套数据库。链同步不等于网页入口已配置；新电脑玩游戏时仍需按原“启动与节点加入操作手册”的网页隧道章节连接同一个游戏 API，之后打开 `http://localhost:8787`。已有网页隧道继续使用。

## 更换服务器（2026-09-28 更新）

升级现有节点：用本次安装器选择原目录重新安装/修复，身份和数据保留。安装后新增 `Change-Server.cmd` 可视化入口和 `Export-Server.cmd`。

原服务器仅 IP 变化时填写新 IPv4；换到另一台同链节点时导入它导出的公开连接 JSON。不同链会被拒绝；会验证对端和区块增长，失败恢复原配置。不会新建测试链。具体步骤见包内 `更换服务器说明.md`。
