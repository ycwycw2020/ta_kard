# 塔卫牌局 · Linux 自适应节点安装包 v1.0.0

《明日方舟：终末地》同人卡牌游戏，非官方二创。此包用于加入现有游戏链，适用于 x86_64 Linux，已在当前 Ubuntu 虚拟机验证。本包加入 2026 年 9 月 27 日建立的现有测试链；9 月 28 日维护保留链与身份。

## 一条命令安装

解压整个安装包，进入解压后的目录，以日常使用的普通用户执行：

```bash
bash Install.sh --server 10.195.244.225
```

这里填写的是**原 Windows 服务器的 WLAN IPv4**，不是新电脑自己的地址。也可直接运行 `bash Install.sh`，按提示输入服务器地址。

自定义安装目录：

```bash
bash Install.sh --server 10.195.244.225 --root "$HOME/我的塔卫节点"
```

默认优先识别已有 `$HOME/talos-extra-node`，否则使用 `$HOME/.local/share/talos/node`。支持中文和空格。两台现有 VMware 虚拟机或同一 VMnet8 中的新虚拟机，也可填可达的原 Windows 地址 `192.168.2.1`。外部电脑填写能实际互通的 WLAN/VPN 地址。

新电脑本机 IP、可用端口自动识别，安装完成后自动启动后台节点。首次联网下载运行环境并核对 SHA-256。Ubuntu/Debian 缺少 curl、tar、xz、unzip 等工具时会调用 apt，可能需要输入这台 Linux 的 sudo 密码；无需把密码写进安装包。

不要用 `sudo bash Install.sh` 来代替普通用户安装。首次需能访问 Node.js、GitHub/Adoptium 下载站点；原服务器必须已运行并允许访问 TCP 30303。其他发行版若缺少基础工具，安装器会列出需要安装的工具。

## 已经安装过怎么办

本次是同链维护，选择原安装目录更新即可，保留节点密钥与链数据。只有仍连接 9 月 27 日之前旧链的设备才需另建目录；安装器会依据创世哈希拒绝混用不同链。

用 `--root` 指向原节点目录，再执行同一命令。旧节点身份、密钥和数据保留，修改过的配置保存在 `backups` 中；自动修复不正确的节点列表和同步配置。

已有健康节点不会重复启动。旧节点若由 systemd 或手动终端运行，先用原服务/终端停止，再运行安装器；新安装器生成自己的启动/状态/停止入口。不要把外部节点安装器指向原有三台验证者的工作目录。

## 启动、查看和停止

以下以默认新目录为例；使用自定义目录时替换路径：

```bash
bash "$HOME/.local/share/talos/node/start-node.sh"
bash "$HOME/.local/share/talos/node/status-node.sh"
bash "$HOME/.local/share/talos/node/stop-node.sh"
```

日志在安装目录的 `logs/node.log`，配置摘要在 `node-settings.json`。安装器使用独立后台进程，关闭安装终端后可继续运行；**重启 Linux 后请执行 start-node.sh**。此版本不自动注册开机服务。

`running: true` 表示进程和 RPC 正常，`peers` 大于 0 表示已连接；首次同步需要时间，应继续观察区块高度逐步接近主链。启动初期 `syncing: false` 不单独代表已经追平。

## 自动化和可选参数

常规使用只需要 `--server`，其余参数可省略：

| 参数 | 用途 |
|---|---|
| `--root PATH` | 自定义安装目录 |
| `--prepare-only` | 准备文件但不启动 |
| `--plan` | 显示检测结果，不修改节点文件 |
| `--runtime PATH` | 复用包含 Besu 26.8.1 和 Java 25.0.4.1+1 的运行环境 |
| `--p2p-port N` / `--rpc-port N` | 指定起始候选端口，占用时自动顺延 |
| `--server-port N` | 原服务器 P2P 不使用 30303 时指定 |
| `--no-prompt` | 自动化部署时禁止交互，需要提供服务器地址 |

安装器自动检测 Node.js 20+，缺少时准备固定版本 Node.js 24.19.0；复用或下载 Java/Besu，下载校验后再安装。Besu/Java 支持中断续传。节点密钥目录权限为 0700，密钥为 0600。RPC 只监听本机回环，外部节点默认是同步节点，不自动加入验证者集合。

建议预留至少 3GB 内存和 10GB 起步磁盘；Java 最大堆为 1GB。运行环境缓存需保留，链数据会继续增长。

## 网页和数据库

此包只安装区块链节点，数据库仍由原 Windows 主机保存。已有虚拟机的网页隧道继续使用；新增电脑若要打开游戏，需要按原“启动与节点加入操作手册”建立到同一个 API 的网页隧道，然后访问 `http://localhost:8787`。无桌面的 Linux 可以只承担链节点职责。

链 ID：`20260926`。合约：`0x192A3cE528978B59e265fd6A3aE3fF6685b6b801`。安装包不包含原服务器私钥、钱包、密码或玩家数据库。

## 更换服务器（2026-09-28 更新）

升级现有节点：用本次安装器选择原目录重新安装/修复，身份和数据保留。安装后新增 `change-server.sh` 和 `export-server.sh`。

原服务器仅 IP 变化时填写新 IPv4；换到另一台同链节点时导入它导出的公开连接 JSON。不同链会被拒绝；会验证对端和区块增长，失败恢复原配置。不会新建测试链。具体步骤见包内 `更换服务器说明.md`。
